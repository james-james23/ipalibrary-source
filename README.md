# IPALibrary source for SideStore / AltStore / LiveContainer

An automatically updated source (catalogue) of the apps listed on <https://ipalibrary.me>,
generated by `scraper.py` and refreshed daily by GitHub Actions.

**Source URL**:

```
https://raw.githubusercontent.com/james-james23/ipalibrary-source/main/ipalibrary_source.json
```

Add that URL as a source in SideStore, AltStore or LiveContainer.

## Run it yourself

```
pip install -r requirements.txt
python -m unittest discover -s tests   # offline tests
python scraper.py                      # writes ipalibrary_source.json
python scraper.py --help               # options
```

Unofficial and not affiliated with iPA Library. The apps themselves are hosted by third parties.
